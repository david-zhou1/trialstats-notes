# TrialStats 可编辑思维导图

打开网站顶部「知识导图」，点击节点并在右侧修改名称、父节点、关联的公开问答；鼠标拖拽节点移动整条分支，滚轮缩放画布，双击节点折叠或展开。

快捷键：Tab 创建子节点，Enter 创建同级节点，Delete 删除，Ctrl+Z 撤销、Ctrl+Y 重做。

**保存规则**：编辑只存储在当前浏览器 localStorage，不会自动写入 GitHub。导出 JSON 进行备份；若要公开更改，将经过审查的 JSON 内容覆盖 `mindmap/map.json` 并提交到 `main`。此 JSON 只保存节点与问答 ID，不保存问答正文。公开问答请在 `questions/questions.json` 中新增或修改，然后在导图编辑器关联对应 ID。

**隐私限制**：公开站点编辑器没有登录鉴权，本地草稿未加密。只用于可公开的专业知识，严禁输入或导入私人笔记、内部研究方案或未经许可的临床数据。私人内容继续保存在独立加密知识库。
